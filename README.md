# Frog_Launch 🐸

*A little piece of the forest on your desktop.*

Лаунчер программ для Windows в стиле ночного болота: матовые «стеклянные» карточки, туман и лягушка. Написан на Object Pascal (Lazarus / Free Pascal).

> **Статус: Alpha (`v0.1.0-alpha`).** Это ранняя версия: возможны ошибки, формат файлов может измениться.

![Frog_Launch](docs/screenshot.png)

## Возможности

- карточки программ со значками, которые лаунчер берёт из самих программ;
- категории (чипы над сеткой) и поиск по названию, `Enter` в поиске запускает первую найденную программу;
- добавление программ кнопкой «Добавить программу», меню по правому клику на карточке: изменить категорию или удалить;
- значок в системном трее: левый клик показывает и прячет окно, правый открывает меню;
- полноэкранный режим на `F11` (выход: `F11` или `Esc` при пустом поиске);
- время, дата и версия внизу окна, приветствие по времени суток;
- программы, которых нет на компьютере, не показываются, но остаются в списке.

## Установка

1. Скачай архив `Frog_Launch_v0.1.0-alpha.zip` в разделе **Releases**.
2. Распакуй его в любую папку. Файл `Frog_Launch.exe` и папка `assets` должны лежать рядом.
3. Запусти `Frog_Launch.exe`.

Windows может показать предупреждение «Windows защитила ваш компьютер» (SmartScreen): программа не имеет цифровой подписи. Нажми «Подробнее», затем «Выполнить в любом случае», если доверяешь источнику.

Проверялось на Windows 11.

## Как добавить программы

Через кнопку «Добавить программу» (выбери `.exe`, придумай название и категорию) или вручную в файле:

```
%LOCALAPPDATA%\Frog_Launch\apps.txt
```

Одна строка равна одной программе, поля разделены чертой `|`:

```
Название | Путь или адрес | Иконка (необязательно) | Категория (необязательно)
```

Примеры:

```
Блокнот|notepad.exe||Системные
Мой сайт|https://example.com||Интернет
Браузер|%LOCALAPPDATA%\Vendor\App\app.exe;%ProgramFiles%\Vendor\App\app.exe||Интернет
```

- строки, которые начинаются с `#`, и пустые строки пропускаются;
- в пути можно использовать переменные Windows (`%ProgramFiles%`, `%LOCALAPPDATA%` и другие) и несколько вариантов через `;`: берётся первый существующий;
- поле иконки это имя файла из папки `assets`; если оно пустое, значок берётся из самой программы.

Файл создаётся при первом запуске со стартовым набором (Блокнот и Калькулятор). Если правишь его вручную, закрой лаунчер: иначе правки могут затереться.

## Сборка из исходников

1. Установи [Lazarus](https://www.lazarus-ide.org/) (проект собран на Lazarus 4.8).
2. Установи пакет **BGRABitmap**: меню «Пакет» → Online Package Manager → `bgrabitmappack`.
3. Открой файл проекта `Frog_Launch.lpi` и нажми `F9`.
4. Положи папку `assets` рядом с получившимся `Frog_Launch.exe`.

## Известные ограничения

- при переключении `F11` окно мигает (Windows пересоздаёт окно при смене рамки);
- сайты и приложения из магазина Windows (адреса `https://...` и `shell:AppsFolder\...`) проверить на существование нельзя, их карточки показываются всегда;
- значки сторонних программ в репозиторий не включены.
